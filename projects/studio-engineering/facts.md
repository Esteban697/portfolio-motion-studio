## The studio project (this repository)

- Local-first pipeline that turns a validated JSON manifest into a video with
  React components and Remotion; explicitly not a general-purpose editor.
  [README.md (intro); docs/architecture.md (Core principle)]
- Remotion 4.0.542, React 19.3.1, TypeScript 5.9.3, Zod 4.6.7; Vitest and
  FFprobe for tests and media inspection. [package.json]
- Manifest parsed and validated once at startup; scene types map to components
  through an exhaustive registry. [src/Root.tsx; src/scenes/registry.tsx]
- Seven scene types and four transitions, all data-driven.
  [src/schemas/project-schema.ts (supportedSceneTypes, transitionNames)]
- Frame timeline rounds per scene then sums, so narration sync cannot drift.
  [src/utils/project.ts (buildSceneTimeline)]
- Narration validation reports overlong audio as an error; it never trims or
  stretches. [src/utils/audio.ts (evaluateNarrationFit)]
- Human approval gates for facts, script, storyboard and final render are
  enforced by `validate --final`. [src/utils/approvals.ts;
  scripts/validate-project.ts]
- Four production skills drive analysis, scripting, storyboarding and
  rendering. [.claude/skills/]
- 123 automated tests at analysis time. [test/]
